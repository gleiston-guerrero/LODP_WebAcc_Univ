## Alcance de este directorio

Aquí se versiona **únicamente el contenido del manuscrito**: el archivo
principal `.tex`, los archivos incluidos, `refs.bib`, las figuras en el
formato en que entran a la compilación, las tablas de apéndice y la carta
de respuesta a los revisores. Nada más.

**No se versiona aquí**, y no debe copiarse aquí:

- datos brutos ni derivados de la auditoría,
- código de recolección ni de análisis,
- el libro de códigos,
- salidas intermedias.

Todo eso vive en el depósito citable
[10.5281/zenodo.22405998](https://doi.org/10.5281/zenodo.22405998),
espejado en `wcag-preconsent-tracking-university-websites`. Ese depósito
es la fuente de registro de cualquier cifra del artículo; este directorio
es la fuente de registro del texto que las reporta.

Cuando una cifra cambie, cambia primero en el depósito y después aquí,
nunca al revés.
